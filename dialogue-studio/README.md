# HeroChat Dialogue Studio

本地图形化编辑器，用来修改 `src/data/home/dialogue.json`。

```bash
npm run dialogue:studio
```

浏览器会自动打开编辑器。默认地址是 `http://127.0.0.1:4319`；如果该端口已被占用，Vite 会自动顺延并在终端打印实际地址。

## 怎么用

- 左侧搜索或选择问题节点。
- 一个问题节点对应一条回答；“回答版本”只是同一回答的随机文案，不会分成不同路线。
- 中间从回答框右侧的圆点拖到另一个问题，表示回答完之后可以继续选它。
- 右侧编辑问题、回答版本、后续可选项、条件和 flag。
- 点“保存到项目”会直接写入 `src/data/home/dialogue.json`。
- “查看 JSON”可复制数据；“放弃修改”可重新读取磁盘。

这个工具只在本地运行，不参与 Astro 生产构建。
